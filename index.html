nyc-map-kit

A basic embedded map: framework-free, no build step, one <iframe>.

This is a prototype, not a City service. It is published so the approach can be reviewed and adapted. It is not operated, monitored or supported, and it has not been through accessibility or security review.

The data is a dated snapshot and is not authoritative. It is a hand export of the SNAP Employment and Training volunteer site list taken in September 2026. Pins are derived by geocoding street addresses, so some are approximate and a few resolve to the wrong building. For current information, use the City's own ABAWD volunteering page, and confirm any specific site with the organization that runs it.
